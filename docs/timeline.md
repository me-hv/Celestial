# Universal Scientific Timeline

## Overview

The Universal Timeline (`/timeline`) serves as the central interactive chronology explorer in CELESTIAL.

---

## Multi-Scale & Multi-Domain Navigation

- **Synchronized Lanes**: `COSMOS`, `ASTRONOMY`, `SPACE_MISSIONS`, `SCIENCE`, `SPACE_WEATHER`, `OBSERVATIONS`, `DATA`.
- **Adaptive Level-of-Detail Scales**:
  - `YEARS` (e.g. Space age mission milestones).
  - `DECADES` (e.g. Modern astrophysical discoveries).
  - `CENTURIES` (e.g. Historical astronomical events).
  - `MILLIONS_OF_YEARS` (e.g. Solar system geological & planetary evolution).
  - `BILLIONS_OF_YEARS` (e.g. Cosmological epochs from Big Bang to Present).

---

## Dual Interface

- **Horizontal Stream Visualizer**: Interactive canvas with chronological baselines and event pins.
- **Accessible Chronological List**: Clean vertical list optimized for mobile viewports and assistive screen readers.
