# Cross-Domain Scientific Intelligence

## Overview

The Scientific Intelligence Engine (`src/domain/intelligence/`) synthesizes multi-domain observations, ground observer geometry, and mission tracking into actionable scientific insights.

---

## Relational Synthesis

1. **Sun → Space Weather → Earth**:
   Solar flare events correlate to ionospheric disturbances and auroral visibility at observer latitudes.
2. **Agency → Mission → Spacecraft → Dataset → Target → Discovery**:
   Unifies hardware telemetry, PDS4 data products, and published peer-reviewed findings.
