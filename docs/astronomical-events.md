# Astronomical Events & Twilight Calculations

## 1. Solar Twilight Standards

| Twilight Phase                 | Sun Solar Depression Angle ($h$) | Observational Visual Effect                                  |
| :----------------------------- | :------------------------------- | :----------------------------------------------------------- |
| **Geometric Sunrise / Sunset** | $h = -0.8333^\circ$              | Top limb of solar disc touches physical horizon              |
| **Civil Twilight**             | $h = -6.0^\circ$                 | Artificial lighting not yet required for outdoor activities  |
| **Nautical Twilight**          | $h = -12.0^\circ$                | Navigational stars visible; horizon distinguishable at sea   |
| **Astronomical Twilight**      | $h = -18.0^\circ$                | Complete absence of solar illumination; true dark sky begins |

## 2. Lunar Synodic Cycle

- Synodic Month: $29.530588853\text{ days}$.
- Phases: New Moon ($D \approx 0^\circ$), Waxing Crescent ($0 < D < 90^\circ$), First Quarter ($D \approx 90^\circ$), Waxing Gibbous ($90^\circ < D < 180^\circ$), Full Moon ($D \approx 180^\circ$), Waning Gibbous ($180^\circ < D < 270^\circ$), Third Quarter ($D \approx 270^\circ$), Waning Crescent ($270^\circ < D < 360^\circ$).
